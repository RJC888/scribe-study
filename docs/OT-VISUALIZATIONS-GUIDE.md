# OT Passage Types: Visualization Matchmaking Guide

This guide shows which visualizations work best for different Old Testament passage categories.

---

## Historical Narrative

**Examples:** 1 Samuel 17 (David & Goliath), Genesis 37-45 (Joseph), Exodus 1-14 (Plagues), 1 Kings 18 (Elijah)

### Best Visualizations

| Rank | Visualization | Why | Example Use |
|------|---------------|-----|-------------|
| 1️⃣ | **Timeline** ⏳ | Shows cause-effect sequence, plot progression | How David defeats Goliath: setup → challenge emerges → tension builds → climax → victory |
| 2️⃣ | **Character Map** 👥 | Multiple characters with clear relationships | David, Goliath, King Saul, Jesse (father), Samuel |
| 3️⃣ | **Mindmap** 🧠 | Themes woven throughout the narrative | Faith, courage, God's provision, unexpected victory |
| 4️⃣ | **Chiasm** 🔺 | Shows literary structure if present | Some narratives use mirror patterns for emphasis |

### Visual Questions Answered

- ✅ **What happens?** → Timeline shows the sequence
- ✅ **Who's involved?** → Character Map shows relationships
- ✅ **What's the big idea?** → Mindmap shows overarching themes
- ✅ **Is there a pattern?** → Chiasm shows mirroring

### User Experience Flow

```
👤 User opens "1 Samuel 17"
↓
System detects: historical-narrative
↓
Carousel Slide 1: Timeline (Event sequence)
                  ↓ User clicks "Next"
Carousel Slide 2: Character Map (Who's involved)
                  ↓ User clicks "Next"
Carousel Slide 3: Mindmap (Core themes)
                  ↓ User clicks "Next"
Carousel Slide 4: [Optional wildcard]
```

## Poetry (Psalms, Song of Songs)

**Examples:** Psalm 23 (Shepherd), Psalm 137 (Lament), Psalm 91 (Protection), Song of Songs 2:8-13

### Best Visualizations

| Rank | Visualization | Why | Example Use |
|------|---------------|-----|-------------|
| 1️⃣ | **Parallelism** 🔄 | Core to Hebrew poetry; shows meaning-making through repetition | Psalm 23: "The Lord is my shepherd" / "I shall not want" |
| 2️⃣ | **Chiasm** 🔺 | Many psalms use mirror structures for emphasis | Psalm structure: A → B → Center (climax) → B' → A' |
| 3️⃣ | **Mindmap** 🧠 | Consolidates imagery and themes | Psalm 23: shepherd care, green pastures, restoration, protection, goodness, mercy |
| 4️⃣ | **Image Cluster** 🖼️ | Groups metaphors and symbols (wildcard if implemented) | All the "shepherd" imagery in one cluster |

### Visual Questions Answered

- ✅ **How does it sound repeated?** → Parallelism shows the structure
- ✅ **What's at the center?** → Chiasm highlights the pivot point
- ✅ **What images dominate?** → Image Cluster groups metaphors
- ✅ **What are the themes?** → Mindmap connects concepts

```

                  ↓ User clicks "Next"
Carousel Slide 2: Chiasm (If structured as mirror)
                  ↓ User clicks "Next"

                  ↓ User clicks "Next"
```

## Tips for Users

1. **Start with the first visualization** — it's ranked best for that passage type
2. **Click "Expand" (+)** on any section to see more detail
3. **Use "Next ▶"** to explore alternative visualizations of the same passage
4. **Look for the wildcard** — the surprising visualization sometimes reveals new insights
5. **Combine with the text** — visualizations are meant to *enhance*, not replace, close reading

## For Developers

To customize the ranking for your use case:

```javascript
// In VisualizationEngine.js, modify genrePreferences:
genrePreferences['historical-narrative'].primary = [
  "timeline",        // Always show timeline first
  "characterMap",    // Then character relationships
  "mindmap"          // Then thematic connections
];

// Or adjust prompt-based boosters:
promptBoosters['devotional'].parallelism = 1.5;  // Boost parallelism for devotional readings
```

To add a new visualization:

```javascript
// 1. Create YourVisualizer.js
export class YourVisualizer {
  constructor(container, context) { ... }
  render() { ... }
}

// 2. Register in VisualizationEngine.js
this.availableVisualizers['yourViz'] = YourVisualizer;

// 3. Add to genre preferences
genrePreferences['poetry'].secondary.push('yourViz');
```

That's it!
